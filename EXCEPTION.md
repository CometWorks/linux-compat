## Your own plugins can stay closed

Under this exception, you may build, use, modify, link, run, host and distribute
independent plugins, mods, UI extensions and services under your own license,
including a proprietary license, without a fee or registration. This also
applies when they run in the same process as this project.

When your extension interacts with this project, directly or through another
component, it must use only the APIs, protocols and runtime hooks the upstream
project documents for third-party use. The permission applies to each
interface's documented use. Separately MIT-licensed SDK, contract and example
code can be used under MIT.

## Core changes

Copying or adapting our AGPL code and editing our source or binary files fall
outside this exception. So does accessing or patching our internals outside the
documented interfaces, even at runtime. Packaging a change as a plugin, wrapper
or service does not bring it within the exception. Copyright law and the AGPL
determine what source must be shared in these cases.

If you change this project, those changes still follow the AGPL. Your
independent extension can stay closed if it uses only the interfaces we
document for third-party use and follows that documentation.

source and required build/install information. Source must match the version

Earlier grants, legal rights and the AGPL's warranty and liability terms stay

We also permit combining, running and distributing this project with separately
licensed Space Engineers client/server binaries, VRage and their supplied runtime
libraries. Their source is not required merely because of that combination.
The game's own terms govern patches to Space Engineers itself. Our AGPL code
