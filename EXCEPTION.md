# Plugin and API exception

This is an additional permission under AGPL section 7, given by the copyright
holders applying it for code they can license. The AGPL itself and its version
choices stay unchanged.

## Your own plugins can stay closed

You may use and distribute your own independent extension under your own
license, even in the same process, if it uses only the interfaces described below
to interact with this project, including through other components, and uses them
as documented.

An interface qualifies when the integration documentation linked from the
upstream [licensing guide](LICENSING.md#integration-interfaces) names it for
third-party use. Use the guide for the release or upstream source revision you
run. Public methods follow the same rule.

Our API's own use of private internals does not turn your API call into
unsupported access.

Separately MIT-licensed SDK, contract and example code can be used under MIT.

## Core changes

Copying or adapting our AGPL code, editing our source or binaries, and
patching private internals fall outside this exception, even when packaged
as a plugin. The AGPL and copyright law determine what source must be shared.

## Other terms still apply

The AGPL still applies to covered code, including notices, modification details,
source and required build/install information. Source must match the version
actually distributed or used remotely, including for section 13 offers.

We welcome fixes and improvements upstream. Contributing is optional and
does not replace required source sharing.

Earlier grants, legal rights and the AGPL's warranty and liability terms stay
unchanged. Section 7 still governs notices, removal and contributions. This file
does not grant permission for another contributor's code without their agreement,
or grant trademark or third-party rights.

## Space Engineers and its libraries

We also permit combining, running and distributing this project with separately
licensed Space Engineers client/server binaries, VRage and their supplied runtime
libraries. Their source is not required merely because of that combination.
The game's own terms govern patches to Space Engineers itself. Our AGPL code
copied into those components remains subject to the AGPL.
